# Монитор раскрытий эмитентов облигаций

Материал команды AI Columbus к анкете этапа SIGNAL IN конкурса Т-Банка «Инвест. Премаркет».

**Страница проекта:** https://voanarges.github.io/bond-disclosure-monitor/

Сервис находит ранние признаки проблем в раскрытиях эмитентов облигаций из портфеля клиента — оговорки аудитора, рост долга, нарушение ковенантов, перенос отчётности — и присылает карточку с фактом, дословной цитатой и ссылкой на документ. Уже случившиеся события (неисполнение обязательств) ловятся правилом без LLM; модель работает только там, где сигнал спрятан в свободном тексте.

На странице: масштаб проблемы по данным Банка России, разделение сигналов на «правило» и «LLM», пример карточки, архитектура MVP на 11 дней с T-Invest API и MCP, ценность для брокера, регуляторные ограничения, дизайн эксперимента без утечки будущего, план и риски.

Это замысел MVP, а не готовый продукт.
